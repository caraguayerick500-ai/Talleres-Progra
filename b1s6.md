### Ejercicio 1: Buscar notas (Option)

Implementa una función `buscarNota` que reciba la cédula de un estudiante y devuelva su nota como un `Option[Double]`. Si el estudiante no existe, devuelve `None`.

Luego, a partir de una lista de cédulas, calcula el promedio de las notas **de los estudiantes que sí existen**.

```scala
case class Estudiante(cedula: String, nombre: String, nota: Double)

val estudiantes = List(
  Estudiante("1101", "Ana", 9.5),
  Estudiante("1102", "Luis", 6.8),
  Estudiante("1103", "Sofía", 8.0)
)

// Implementa tu función aquí
def buscarNota(cedula: String): Option[Double] = if (estudiantes.exists(_.cedula == cedula))
  Some(estudiantes.find(_.cedula == cedula).get.nota)
else
  None

// Pruebas
println(buscarNota("1101"))   // Some(9.5)
println(buscarNota("9999"))   // None

val cedulas = List("1101", "9999", "1103", "0000")
val notas = cedulas.map(buscarNota)

val existentes = notas.flatten
val promedio = existentes.sum / existentes.size   // 8.75
```

### Ejercicio 2: Comprar entradas (Either)

Implementa una función `comprarEntrada` que reciba un `Evento`, la edad y el saldo de un usuario, y devuelva un `Either[String, Double]` con el saldo restante.

**Reglas** (en este orden):

1. Si el evento no tiene cupos, devuelve `Left("Evento agotado")`
2. Si la edad es menor a la edad mínima, devuelve `Left("No cumple la edad mínima")`
3. Si el saldo es menor al precio, devuelve `Left("Saldo insuficiente")`
4. En otro caso, devuelve `Right` con el saldo restante

Luego, usando `match`, genera un mensaje por cada evento de la lista para un usuario de **17 años** con **50.0** de saldo.

```scala
lista.map(elemento =>
  funcion(elemento) match {
    case Right(valor) => // qué hacer si la operación fue exitosa
    case Left(error)  => // qué hacer si hubo un error
  }
)
```
